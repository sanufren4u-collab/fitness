## Multi-vendor setup

This app supports multiple gyms on one shared website. Each account is assigned to a gym, and staff, members, plans, classes, bookings, and billing records are scoped to that gym.

Apply database migrations before deploying:

```bash
npx prisma migrate deploy
```

Existing gym data is assigned to the default Byayamshala vendor. The oldest existing admin account becomes the platform administrator; other admins remain scoped to Byayamshala. Platform administrators can manage vendor accounts at `/admin/vendors`; creating a vendor also creates its first gym admin account. Users sign in on the shared site with their own account, which determines their gym. Deactivating a vendor blocks its gym users from signing in and accessing tenant data.
